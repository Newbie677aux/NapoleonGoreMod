# NapoleonGoreMod

Мод крови/расчленёнки для Napoleon: Total War (поверх DarthMod), отдельным `.pack`.
Оригинальные паки игры и файлы DarthMod не изменяются.

## Шаги 1–2: бэкап и разведка

`tools/step1_backup_and_recon.ps1` — только копирует и читает, в игре ничего не меняет:

1. Копирует `save_games` и `scripts\user.script.txt` в
   `%APPDATA%\The Creative Assembly\Napoleon\_backup_2026-10-13` и сверяет хэши.
2. Читает индексы всех `data\*.pack` (без распаковки), ищет файлы DarthMod,
   переопределения между паками, эффекты/декали/variantmesh/звуки.
3. Складывает отчёт в `_backup_2026-10-13\recon\` и `recon.zip`.

Запуск (PowerShell):

```
powershell -ExecutionPolicy Bypass -File tools\step1_backup_and_recon.ps1
```

## Шаг 3: что реально сделать

Отчёт: [docs/step3_report.md](docs/step3_report.md). Кратко:

- **Да:** кровь от пуль и ядер (правка `effects\landbattle.xml`, взятого из DarthMod), звуки попаданий (WAV по путям USM).
- **Нет:** пятна на земле, отлетающие головы, дыры в телах, агония/раненые — движок этого не умеет\n  (подробности ниже; в отчёте шага 3 пятна ещё значились «частично», потом проверено — нельзя).

## Сборка и установка

```
powershell -ExecutionPolicy Bypass -File tools\build_pack.ps1             # собрать и положить в data\
powershell -ExecutionPolicy Bypass -File tools\build_pack.ps1 -Uninstall  # убрать мод
```

Результат: `data\zz_NapoleonGoreMod.pack` (movie-пак, `user.script.txt` не трогается).
Префикс `zz_` обязателен: так пак грузится после `DMN_*` и перекрывает их `landbattle.xml`.
Это проверено в игре через `tools\build_test_pack.ps1`, где у паков разные цвета крови.

Сейчас в моде:

**Кровь** (`effects\landbattle.xml` DarthMod, изменены только 4 эффекта крови и 2 группы):
- своя текстура `gore_blood_diffuse.tga`: форма брызг DarthMod, цвет тёмной крови;
- пуля/картечь в человека (`Musket_impact_human`): струйка + веер брызг (по 2 капли на точку) + красное облачко `blood_mist`;
- ядро в человека (`blood_spray`): крупный выброс + брызги + облачко;
- лимиты под слабые видеокарты: 60–200 эффектов на тип, ≤2000 квадов на всю кровь, капли живут 1–2 с.
- картечь отдельно не нужна: по таблицам её снаряды бьют с типом `musket_ball`/`naval_grape`, у которых
  при попадании в человека тот же `Musket_impact_human`.

**Пороховой дым** (те же эффекты DarthMod, `-NoSmoke` — не трогать):
- ближняя граница `min_lod`: облако ближе 25 м к камере (мушкетный дым у линии — 12 м) не рисуется,
  чтобы при нырке камерой в дым экран не заливало слоями (в ванили было 10–90 м, у DarthMod 0,5–1 м);
- мушкетный и пушечный дым тает только последние 35% жизни вместо 60% — после залпов висит пелена;
- основной мушкетный клуб: 2 частицы вместо 3; большая пелена живёт 60 с (как в ванили) вместо 45.
- смысл `min_lod` выведен из настроек ванили; подтверждается в игре (облако «расступается» перед камерой).
**Звуки** (`tools\build_sounds.ps1`, из CC0-записей в `sounds\src`, см. `sounds\src\SOURCES.md`;
лежат по путям Ultimate Sound Mod и перекрывают его):
- пуля в тело, ядро по людям, сабля по телу (синтезированный свист клинка), штык в тело — по 8 вариантов;
- стоны: в каждый `-VoiceEvery`-й вариант почти вплотную к удару вклеен стон/крик из голосов самой игры
  (`tools\build_voices.ps1`: актёр 1 шести наций, громче до x3). По умолчанию 2 — в половине вариантов;
  проверочная сборка `-VoiceEvery 1` — во всех.

Без звуков: `tools\build_pack.ps1 -NoSounds`. Без стонов (только удары): `-NoVoices`.

**Что пробовали и убрали:** громкие версии всех 266 `death_cry_fall_scream.mp3` и событие 102 в 254
анимациях смерти как «крик». В игре криков не стало слышно вообще: `death_cry`, похоже, — крик при падении
(со стены/корабля), а 102 — не крик. Старые версии пака — в `_backup_2026-10-13\mod_versions`.
## Проверка

```
powershell -ExecutionPolicy Bypass -File tools\verify_pack.ps1
```

Без запуска игры: структура пака, XML эффектов, текстура, формат WAV/MP3, события смерти,
что каждый путь перекрывает настоящий файл игры, что паки игры/DarthMod не менялись.
`tools\dbdump.ps1` — грубый разбор db-таблиц без схемы (так проверена картечь).

## Чего нет и не будет

- пятен крови на земле: воронки от ядер движок рисует из кода, а частицы не умеют ложиться на рельеф;
- голов, дыр в телах, агонии и раненых: смерть — одна анимация падения, своих `.anim` без инструментов не сделать;
- крови в рукопашной: эффекты движок вызывает только при попадании снаряда.
